INSTALLATION
────────────────────────────────────────
1. Extract EGMdL.zip — you'll find "EGM Downloader.AppImage" inside
2. Make it executable:
      chmod +x "EGM Downloader.AppImage"
3. Double-click to launch, or run from terminal:
      ./"EGM Downloader.AppImage"

That's it. No install step, no root required.

On first launch, ffmpeg (~90 MB) and Deno download automatically in the background.
This only happens once.


UBUNTU 22.04+ / libfuse2 NOTE
────────────────────────────────────────
If the app doesn't launch on Ubuntu 22.04 or newer, install libfuse2:

   sudo apt install libfuse2

Then try launching again.

UPDATING
────────────────────────────────────────
EGM Downloader does not auto-update on Linux.
Check egerena.com/apps/egml.html for new releases.

yt-dlp and ffmpeg can be updated from inside the app:
Settings → Update Plugins → Check for Updates


UNINSTALLING
────────────────────────────────────────
Delete the AppImage file. Nothing else is installed system-wide.

Settings, history and other app data are stored in ~/.local/share/egm-downloader.
The app window keeps its own browser data (cache and saved themes) in ~/.config/egm-downloader.
Delete both folders if you want a clean removal.
