INSTALLATION
────────────────────────────────────────
1. Extract EGMdL.zip — you'll find "EGM Downloader.AppImage" inside
2. Make it executable:
      chmod +x "EGM Downloader.AppImage"
3. Double-click to launch, or run from terminal:
      ./"EGM Downloader.AppImage"

That's it. No install step, no root required.

On first launch, ffmpeg (~90 MB) and Deno download automatically in the background.
This only happens once.


UBUNTU 22.04+ / libfuse2 NOTE
────────────────────────────────────────
If the app doesn't launch on Ubuntu 22.04 or newer, install libfuse2:

   sudo apt install libfuse2

Then try launching again.


.DEB PACKAGE (DEBIAN, UBUNTU AND RELATIVES)
────────────────────────────────────────
The same app is also offered as EGMdL.deb, a separate download for
64-bit Debian, Ubuntu and distributions built on them.

If you are updating, close EGM Downloader first.
Install it, or update to a newer one (the new file installs over the old):

   sudo apt install ./EGMdL.deb

Then open "EGM Downloader" from the applications menu, or run:

   egm-downloader

If the app doesn't open, start it from a terminal without Chromium's
sandbox, and let us know (see SUPPORT):

   egm-downloader --no-sandbox

Or use the AppImage from EGMdL.zip instead (see INSTALLATION).

The .deb needs no libfuse2. It uses the same settings and history folder
as the AppImage, so you can move from one to the other and keep everything.

To remove it:

   sudo apt remove egm-downloader

Removing the package leaves your settings and history in place
(see UNINSTALLING for the two folders).


.RPM PACKAGE (FEDORA AND OPENSUSE)
────────────────────────────────────────
The same app is also offered as EGMdL.rpm, a separate download for
64-bit Fedora 45, openSUSE Tumbleweed and openSUSE Leap 16.1.

If you are updating, close EGM Downloader first.
Install it, or update to a newer one (the new file installs over the old).

On Fedora:

   sudo dnf install ./EGMdL.rpm

On openSUSE:

   sudo zypper install --allow-unsigned-rpm ./EGMdL.rpm

The package is not signed. dnf says that it skipped the signature check.
zypper stops at an unsigned file unless --allow-unsigned-rpm is given.
Check the file against the SHA256 on the download page before installing.

Then open "EGM Downloader" from the applications menu, or run:

   egm-downloader

If the app doesn't open, start it from a terminal without Chromium's
sandbox, and let us know (see SUPPORT):

   egm-downloader --no-sandbox

Or use the AppImage from EGMdL.zip instead (see INSTALLATION).

The .rpm needs no FUSE. It uses the same settings and history folder
as the AppImage, so you can move from one to the other and keep everything.

To remove it:

   sudo dnf remove egm-downloader         (Fedora)
   sudo zypper remove egm-downloader      (openSUSE)

Removing the package leaves your settings and history in place
(see UNINSTALLING for the two folders).

UPDATING
────────────────────────────────────────
EGM Downloader does not auto-update on Linux.
Check linux.egmdownloader.app for new releases.

yt-dlp and ffmpeg can be updated from inside the app:
Settings → Update Plugins → Check for Updates


UNINSTALLING
────────────────────────────────────────
AppImage: delete the AppImage file. It installs nothing else on the system.
.deb or .rpm: remove the package with the command in its section above.

Settings, history and other app data are stored in ~/.local/share/egm-downloader.
The app window keeps its own browser data (cache and saved themes) in ~/.config/egm-downloader.
Delete both folders if you want a clean removal.
