EGM Downloader — Installation & Setup Guide
============================================
https://windows.egmdownloader.app


REQUIREMENTS
─────────────
  • Windows 10 or 11 (64-bit)

  Nothing else to install: EGM Downloader brings its own Python and
  everything the app runs on. Two tools (ffmpeg and Deno) are downloaded
  automatically on first launch — no manual setup required.


INSTALLATION
─────────────
  1. Run egm-setup.exe
  2. Choose an install folder (default is recommended)
  3. Click Install
  4. Check "Launch EGM Downloader" on the finish screen, or run it
     from the Start Menu shortcut created during install


FIRST LAUNCH
─────────────
  The first time you run the app, it downloads two tools in the
  background (one time only):

    • ffmpeg   (merges and converts video and audio)
    • Deno     (a JavaScript runtime some downloads need)

  This may take a few minutes depending on your connection speed.
  Subsequent launches are near-instant.


UPDATING
─────────
  To update yt-dlp or ffmpeg (recommended periodically):
    Open the app → Advanced → Plugins → click "Check for Updates",
    then "Install Updates"

  To update EGM Downloader itself:
    Download the latest egm-setup.exe from https://windows.egmdownloader.app
    Run it over your existing install — your settings are preserved.
    Installing over an older version (v1.5.0 or newer) also keeps your
    history, logs and the downloaded ffmpeg and Deno.


UNINSTALLING
─────────────
  Open Windows Settings → Apps → search "EGM Downloader" → Uninstall
  Or run uninstall.exe in your install folder.

  The uninstaller asks two questions: whether to also remove the
  downloaded tools (ffmpeg and Deno), and whether to also remove your
  data (settings, download history, cookies, logs). Answer Yes to both
  to leave nothing behind.

  Your download folder and its contents are never deleted by the
  uninstaller — only the application files are removed.


TROUBLESHOOTING
────────────────
  "Python could not start" on launch
      → The Python that comes with EGM Downloader could not start.
        Antivirus software may have blocked or removed one of its files.
      → If your antivirus quarantined a file of EGM Downloader, restore
        it, then reinstall EGM Downloader: run egm-setup.exe again
        (choose Repair if it asks) — your settings are preserved

  Downloads fail or show errors
      → Open Update Plugins and update yt-dlp to the latest version
      → For age-restricted content, use the Site Cookies feature

  Need more detail about a problem
      → The log file is egm_debug.log, saved in your install directory
        (egm_debug.log.old is the previous one)
