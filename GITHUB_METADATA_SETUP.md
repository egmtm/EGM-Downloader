# GitHub Repository Metadata Setup Guide
**Repository:** https://github.com/egmtm/EGM-Downloader  
**Purpose:** Set description, topics, and website URL

---

## 📋 INSTRUCTIONS

These settings must be configured on the GitHub website. They cannot be set via git commits.

**Time required:** 3 minutes

---

## 🔧 STEP-BY-STEP

### 1. Go to Repository Settings

**URL:** https://github.com/egmtm/EGM-Downloader/settings

Or:
1. Go to https://github.com/egmtm/EGM-Downloader
2. Click the "⚙️ Settings" tab at the top

---

### 2. Set Repository Description

**Location:** Top of Settings page, "Description" field

**Copy and paste this EXACT text:**
```
Multi-platform video downloader for 1000+ sites. Built with yt-dlp, Flask, and Electron.
```

**Action:** 
- Click the description field
- Paste the text above
- Click "Save changes" or just click outside the field (auto-saves)

---

### 3. Set Website URL

**Location:** Same area, "Website" field (right below description)

**Copy and paste this EXACT URL:**
```
https://egerena.com
```

**Action:**
- Click the website field
- Paste the URL above
- Auto-saves

---

### 4. Add Topics (Tags)

**Location:** Scroll to "Topics" section (or on main repo page, click "⚙️" next to "About")

**Add these 10 topics ONE BY ONE:**

**Copy each topic below and add them:**
1. `video-downloader`
2. `yt-dlp`
3. `electron`
4. `flask`
5. `python`
6. `javascript`
7. `cross-platform`
8. `youtube-downloader`
9. `multi-platform`
10. `desktop-app`

**How to add:**
- Click "+ Add topics" or the topics field
- Type or paste each topic
- Press Enter after each one
- Topics auto-save

**Note:** Topics must be lowercase with hyphens (no spaces)

---

## ✅ VERIFICATION

### After Setting Everything:

**1. Check main repository page:**
- Visit: https://github.com/egmtm/EGM-Downloader
- You should see:
  - Description at the top: "Multi-platform video downloader..."
  - Website link: 🔗 egerena.com
  - Topics as clickable tags below description

**2. Check "About" section (right sidebar):**
- Description visible
- Website clickable
- Topics listed

**3. Topics make repository searchable:**
- Clicking any topic shows other repos with that tag
- Helps people discover your project
